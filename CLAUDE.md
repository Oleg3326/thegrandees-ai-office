# AI Office (форк)

Форк https://github.com/AlexanderGrandees/thegrandees-ai-office (MIT): пиксельные
живые обои Wallpaper Engine, показывающие активность ИИ-программ на ПК.
Только личное использование, Windows. Общаемся по-русски, перед большими правками
показывай план.

## Архитектура
- index.html (~195 КБ, одна страница, canvas 384x216 в масштабе x2): сцена, боты,
  панель. Каждые 2 с опрашивает GET /state.
- office-server.mjs: локальный сервер 127.0.0.1:7777. Раз в 4 с сканирует процессы,
  принимает POST /event от хуков, отдаёт /state.
- hook.mjs: хук Claude Code/Codex. Шлёт события на сервер и считает размер контекста
  по хвосту файла транскрипта.
- install-hooks.mjs: прописывает хуки в ~/.claude/settings.json (и в Codex).
- windows/install.ps1 ставит в %LOCALAPPDATA%\TGTI-AI-Office; из папки репозитория
  запускается через install-windows.cmd. Установленная копия отдельная: после правок
  установщик нужно запускать заново. Быстрый просмотр интерфейса: index.html#demo.

## Уже сделано
- Автообновление из репозитория автора отключено.
- Субагенты Claude Code (SubagentStart/Stop, agent_id) как отдельные боты в касках.
- Шкала контекста под табличкой и стопка бумаг у стола.
- Красные глаза и монитор при PostToolUseFailure.
- Диагностика (шаг 1) пройдена: после переустановки ctx и субагенты (sub: true) приходят в /state;
  серверная часть проверена через test-agent.mjs. С реальным субагентом Claude Code не проверялось.
- Ракета и бусификация вырезаны целиком (сцены, кнопка, звуки, away/held/doc/gen, пункт меню macOS).
  Брифинг оставлен по решению владельца.
- Интерфейс переведён на русский (index.html, project.json): реплики, диалоги, статусы, кнопки.
  В репликах «ё» не использовать (в пиксельном шрифте её может не быть), писать «е». Версия v1.8.
- Регион (часы, восход/закат, сезон «Авто») выбирается кнопкой в панели, список REGIONS в index.html,
  по умолчанию Москва, выбор хранится в localStorage (office-region).
