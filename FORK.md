# Форк: субагенты и метрики

Основа: [AlexanderGrandees/thegrandees-ai-office](https://github.com/AlexanderGrandees/thegrandees-ai-office) (MIT, лицензия сохранена в `LICENSE`). Весь пиксельный арт, сцена, погода и звуки остались оригинальными, поэтому оригинального автора стоит упомянуть, если выложишь на GitHub.

## Что добавлено

**Субагенты Claude Code как отдельные боты.** Хуки `SubagentStart` / `SubagentStop` создают и убирают бота. Субагент заходит с улицы пешком (без машины), садится за свободный стол, носит жёлтую каску, на табличке у него тип («EXPLORE», «PLAN»…), а в панели справа строка «Claude Code › Explore». Работает он с теми инструментами, которые вызывает сам (события с `agent_id` относятся к нему, а не к родителю). Даже мгновенный субагент остаётся в офисе минимум 8 секунд, чтобы успеть дойти до стола. Максимум 4 субагента на сессию.

**Метрики (только Claude Code):**
- Контекст: шкала под табличкой (зелёная до 60%, жёлтая до 85%, дальше мигает красным), процент в панели и стопка бумаг у стола (2, 4 или 6 листов, при 90%+ ещё летает листок).
- Ошибка инструмента (`PostToolUseFailure`): глаза бота и монитор мигают красным 8 секунд, бот говорит реплику.

**Служебное:** автообновление из репозитория автора отключено (оно каждые 15 секунд ставило бы код оригинала поверх твоих правок; включить обратно можно через `OFFICE_ALLOW_UPDATE=1`). При локальной установке не отправляется запрос «счётчика установок».

## Установка на Windows (из этой папки)

Распакуй архив и дважды кликни `install-windows.cmd`. Он ставит код из этой папки (а не из репозитория автора). То же самое из PowerShell:

```powershell
cd путь\к\этой\папке
$env:TGTI_SOURCE = (Get-Location).Path
powershell -ExecutionPolicy Bypass -File .\windows\install.ps1
```

Потом **перезапусти Claude Code** (он читает хуки при старте), в Wallpaper Engine выбери обои «AI Office (fork…)» во вкладке Installed. Повторный запуск установщика обновляет файлы.

## Проверка

- Без реальных агентов: открой `index.html#demo` в браузере. В демо два субагента появляются на ~28 секунд каждые 45, у одного «ошибка», у Claude 82% контекста.
- Через сервер: при открытых обоях в папке `%LOCALAPPDATA%\TGTI-AI-Office` выполни `node test-agent.mjs TEST`. Бот зайдёт, запустит двух субагентов, поймает ошибку и дойдёт до 97% контекста.

## Допущения и ограничения

- Размер окна контекста угадывается: больше 200k токенов в контексте считаем окном в 1M. Если у тебя другое, задай `OFFICE_CTX_MAX=число` (переменная окружения сервера).
- Контекст берётся из последнего ответа в файле транскрипта Claude Code (читается только хвост файла, наружу из хука уходит одно число токенов). Для Codex, ChatGPT и приложения Claude его нет.
- Токены в секунду и лимиты: хуки этих данных не дают, поэтому не сделано.
- Субагентов у Codex нет, у ChatGPT и приложения Claude нет хуков, поэтому они остались как в оригинале.
- Новые реплики написаны по-украински, как и остальной интерфейс.
